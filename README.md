# GraphicsEngine

A simple 3D graphics engine using Vulkan as a backend. The demo project can be built from `CMakeLists.txt` (tested with MSVC compiler for amd64 architecture).
The engine is compiled to a statically linked library that can be included in any project that wants to use it. ImGui support and Profiling can be optionally enabled.
